# TESS Transit Hunter

A Python toolkit and analysis pipeline for downloading, detrending, and searching NASA TESS light curves for exoplanet transit signals.

## Project Structure
- `notebooks/` — Exploratory Jupyter notebooks for target analysis and plotting.
- `src/` — Core Python scripts for data preprocessing, BLS periodograms, and transit modeling.
- `requirements.txt` — Required Python packages.

## Setup
```bash
git clone [https://github.com/](https://github.com/)<your-username>/tess-transit-hunter.git
cd tess-transit-hunter
pip install -r requirements.txt
